# Base de connaissances du support YourMovie's

## Comptes et YM Coins

- Les YM Coins sont liés au compte YourMovie's, pas directement au profil Discord.
- Pour recevoir les récompenses Discord, l'utilisateur ouvre Paramètres > Discord sur le site, génère un code temporaire, puis exécute `/lier CODE` sur le serveur.
- Le code est personnel, à usage unique et expire après 10 minutes.
- La commande `/solde` affiche le solde et le nombre de boosts comptabilisés.
- La commande `/economie` affiche les règles de récompense en vigueur.
- Les montants et prix présents dans le contexte dynamique priment toujours sur ce document.

## Activité Discord

- Les messages, réactions et commandes partagent le même cooldown : les multiplier ne contourne pas la limite.
- Les bots, webhooks, messages privés et événements dupliqués ne donnent rien.
- Un plafond journalier empêche le farm excessif.
- Le bump est compté séparément et uniquement après la confirmation du bot de bump dans le salon configuré.

## Boosts

- 1 à 2 boosts actifs comptabilisés donnent Basic.
- 3 à 5 boosts actifs comptabilisés donnent Standard.
- 6 boosts actifs ou plus donnent Premium.
- Le bonus Discord est séparé d'un abonnement acheté ou obtenu avec des YM Coins.
- Quand le membre ne booste plus, seul le bonus Discord est retiré.
- Si le nombre historique est incorrect, le staff peut le corriger avec la commande `/boosts`.

## Support

- L'assistant peut expliquer le fonctionnement public de YourMovie's, des YM Coins, de la liaison Discord et des boosts.
- Les prix monétaires et les prix en YM Coins doivent venir des données dynamiques fournies par l'API.
- Les paiements, remboursements, problèmes contenant des données privées et demandes administratives doivent toujours être transmis au staff.
- Il ne faut jamais demander un mot de passe, un code de carte bancaire, un code Paysafecard, un token ou une clé API.
- Si une information n'est pas présente ici ou dans les données dynamiques, il faut transmettre au staff.
